🚀 DEPLOY PHISHGUARD AI TO RENDER - QUICK GUIDE
==================================================

STEP 1: PUSH TO GITHUB
-----------------------
git init
git add .
git commit -m "PhishGuard AI - Initial commit"
git remote add origin https://github.com/YOUR_USERNAME/PhishGuard-AI.git
git push -u origin main

STEP 2: DEPLOY TO RENDER
-------------------------
1. Go to: https://dashboard.render.com/
2. Click: "New +" → "Web Service"
3. Connect your GitHub repository
4. Configure:
   - Name: phishguard-ai
   - Environment: Docker
   - Plan: Free
5. Add Environment Variable:
   - Key: VT_API_KEY
   - Value: YOUR_VIRUSTOTAL_API_KEY
6. Click: "Create Web Service"
7. Wait 5-10 minutes

STEP 3: ACCESS YOUR APP
------------------------
Your app will be live at:
https://phishguard-ai.onrender.com

(Replace with your actual service name)

API Docs: https://your-app.onrender.com/docs
Health: https://your-app.onrender.com/health

THAT'S IT! 🎉

Your PhishGuard AI is now live on the internet!
